# مطعم دجاجة بالقنية (Dajaja Bil Qanniyeh)
> **« من طلبك تبدأ الحكاية »**  
> تطبيق قائمة طعام وطلب سريع متكامل مبني باستخدام **Angular 17+ (Standalone + Signals)** مع واجهة عربية أصيلة بنمط RTL وتصميم مستوحى من مطاعم ومشاوي الحطب الأردنية التقليدية.

---

## 🍗 نبذة عن المشروع
تم تصميم وتطوير هذا المشروع بالاعتماد على منهجية **UI/UX Pro Max** لتقديم تجربة حجز وطلب طعام سريعة، ممتعة، ومخصصة للهواتف المحمولة أولاً (Mobile-First):
- **الهوية البصرية:** طابع مشاوي الحطب العتيق، ألوان الجمر والبهارات الأردنية، أختام المحمرة الذهبية، وأوراق الجزارين الدافئة.
- **الخطوط والطباعة:** توافق خطوط عربية فائقة الوضوح (`Cairo` للعناوين والأختام، `Tajawal` للمحتوى والقوائم، و `Amiri` للشعارات واللمسات التقليدية).
- **أيقونات SVG مخصصة بالكامل:** رسومات متجهة دقيقة ومصممة يدوياً لكل وجبة، مرفق، وإضافة بدون الاعتماد على الإيموجي أو مكاتب الأيقونات العامة.
- **تفاعل لحظي ذكي:** حساب فوري للمجموع، تحديد متعدد للإضافات، وإنشاء رسالة طلب مهيأة مسبقاً لتطبيق واتساب مع دعم الاتصال الهاتفي المباشر.

## 🚀 التشغيل السريع (Getting Started)

### المتطلبات الأساسية
- Node.js (v18+ أو أحدث)
- npm (v9+ أو أحدث)
- Angular CLI 17+ (أو استخدام `npx ng`)

### خطوات التثبيت والتشغيل
```bash
# 1. الدخول إلى مجلد المشروع
cd dajaja-bil-qanniyeh

# 2. تثبيت الحزم (إذا لم تكن مثبتة بالفعل)
npm install

# 3. تشغيل خادم التطوير المحلي
npm start
# أو
ng serve
```

ثم افتح المتصفح على الرابط: **`http://localhost:4200/`**

### بناء نسخة الإنتاج (Production Build)
```bash
npm run build
```

### تشغيل الاختبارات (Unit Tests)
```bash
npm test -- --watch=false
```

## 💡 المميزات التقنية وتجربة المستخدم (Key Features)

1. **Angular 17+ Standalone & Signals First:**
   - استغناء تام عن NgModules.
   - استخدام `signal()` و `computed()` في `OrderService` لحساب الأسعار والرسائل في زمن حقيقي بدون أي Rerender زائد.
   - تطبيق نمط `ChangeDetectionStrategy.OnPush` على كافة المكونات لأقصى أداء ممكن.

2. **إمكانية الوصول (Accessibility - a11y):**
   - سمات `aria-checked`، `role="radiogroup"`، `role="radio"`، `role="checkbox"`.
   - دعم كامل للوحة المفاتيح (مفاتيح Space / Enter للتنقل والتحديد).
   - تباين ألوان يتجاوز معايير WCAG AAA للنصوص الرئيسية والفرعية.
   - حالات تركيز واضحة (`:focus-visible`).

3. **تجربة طلب متكاملة على واتساب وهاتفياً:**
   - زر الطلب عبر واتساب يولد رسالة منسقة بالعربية تشمل اسم الوجبة، نوع التقديم، قائمة الإضافات، والمجموع الكلي بدقة.
   - زر اتصال فوري للرقم: **`0789898226`**.
   - زر لنسخ ملخص الفاتورة بنقرة واحدة مع تنبيه منبثق (Toast).
